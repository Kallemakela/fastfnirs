
## `SphereProjector.py`

Projects points (sensors) from a 2d plane to a 3d sphere. Used to create custom 3d montages, e.g. `scripts/grid/nemo_3d_montage.py`.

## `StdMontageMapper.py`

Maps signals from a set of original channels to a set of standard channels.

## `BrainLocalizer.py`

Class for localizing channels on a montage. Used to e.g. get a subset of standard montage sensors that are closest to given channels.
